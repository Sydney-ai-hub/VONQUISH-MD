
# ☁️ VONQUISH MD – Deployment Guide

## 🚧 Deployment Status

VONQUISH MD is still under development. Public multi-user deployment is not ready yet.

The current WhatsApp bot runs locally and is designed for one WhatsApp account. The online pairing feature is not enabled yet.

## 💻 Run Locally

1. Install Node.js.
2. Clone the repository:

   `git clone https://github.com/Sydney-ai-hub/VONQUISH-MD.git`

3. Open the project folder:

   `cd VONQUISH-MD`

4. Install dependencies:

   `npm install`

5. Start the local bot:

   `node index.js`

## 🔒 Before Public Deployment

The project needs:

- Secure user authentication.
- Separate WhatsApp sessions for each user.
- Persistent and protected session storage.
- Secure environment variables.
- Rate limiting and error handling.
- A hosting service that supports persistent storage.

## ⚠️ Security

- Never upload `.env` files.
- Never upload WhatsApp session folders.
- Never share pairing codes or session credentials.
- Only connect WhatsApp accounts you own or have permission to use.
